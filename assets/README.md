([LICENSING.md](../LICENSING.md)).

| File | Use |
|---|---|
| `logo/mini-albertcode-logo.png` | The logo, 1024×1024; shown at the foot of the README |
| `logo/mark.svg` | The app icon: the mark on its dark tile (GitHub dark mode, terminals, social) |
| `logo/mark-light.svg` | The app icon for light backgrounds (the same tile, which reads on both) |
| `logo/glyph.svg` | The mark without its tile; its cursor takes the surrounding text colour |
| `logo/favicon-32.png`, `logo/icon-180.png`, `logo/icon-512.png` | Favicon, touch icon, app icon |

| `readme/icon-*.svg` | The icons of *Why mini-AlbertCode* |
| `readme/screen-*-dark.png`, `readme/screen-*-light.png` | Screenshots, for dark and light mode |
| `social/social-preview.png` | The repository's social preview, 1280×640 |

The screenshots are of one task in a small example shop, a percentage discount fixed and tested,
followed in both interfaces: the plan (`screen-plan`), the result (`screen-outcome`), the diff
(`screen-diff`), the task in full (`screen-evidence`), the same task in the terminal
(`screen-terminal`), the terminal's welcome, help and *Connect a provider* (`screen-terminal-home`,
`screen-terminal-help`, `screen-connect`), and a question answered in the Ask only mode (`screen-ask`).

The mark is a terminal prompt (`>`) beside a cursor with a checkpoint on it, inside a rounded frame: the
agent works, and stops for your approval.

| Colour | Hex |
|---|---|
| Tile | `#0D0D0D` |
| Signal orange | `#F26B3A` |
| Cursor | `#E4E4E4` |

Leave the mark unaltered: don't recolour, stretch or outline it, and keep clear space of at least a
quarter of its width around it.
